## 與 Tap 有交集的行為

- `35ca204a` 將 `x-codex-turn-metadata` 常數從 `core/src/client.rs` 移到 `codex-api/src/requests/headers.rs`。即時媒體、圖片後端和 Responses 共用同一個標頭名稱，變更前後使用相同字串。圖片擴充另改由宿主提供執行緒設定。Tap 的 [帳號操作](../../crates/upstream/src/ops.rs) 從控制面取得圖片的 turn id 和 metadata，改寫 metadata 的安裝 id 後轉送。

- `7f8dcb3e` 和 `39f38dcf` 涉及終端偵測。前者新增 Ghostty 色彩判斷，既有 Ghostty 終端名稱映射不變。後者新增 VS Code 容器剪貼簿判斷。兩者均未改 User-Agent 所使用的終端識別結果。
