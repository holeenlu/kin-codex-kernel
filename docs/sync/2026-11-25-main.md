## 與 Tap 有交集的行為

- `cba3c40c` 延後的是代理端把 `output_item.added` 轉成 `TurnItem` 的工作，當 mailbox drain 或 extension contributor 暫停向用戶端輸出時，等 `output_item.done` 再組 UI 項目。Tap 的 HTTP `TerminalDecoder` 原本就只在終態完整解析 JSON。WS 非串流回應也只交付終態，原始串流照常逐事件轉送。WS 續接仍讀取 `output_item.added` 的索引，以辨識未完成項目與稀疏終態，並在完成後計算指紋。既有測試涵蓋 HTTP 終態完整抵達後立即回傳、WebSocket 非串流、原始 SSE 及增量續接。
- `6b7a16fe` 刪除無呼叫者的官方 HTTP builder、raw-body helper 與 cookie pool 建構方法。Tap 獨立使用鎖版的 `reqwest`、每帳號 cookie 和代理設定，未引用被移除的入口。官方起訖鎖檔只刪除 `codex-agent-extension` 與 `codex-utils-readiness` 的 workspace 記錄。
- `77acaa20` 把遭拒的本機音訊檔案 ID 從官方 `ErrorEvent` 移到宿主內部。Tap 的 Responses 路徑沒有檔案復原狀態，保留上游事件與既有私有錯誤收據契約。
