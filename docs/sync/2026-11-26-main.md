## 與 Kin 有交集的行為

- CPR 的 OAuth、換票與額度查詢改為在背景操作執行時讀取全域身分，推理保留 Client Key 覆寫。Kin 的[身分設定](../../crates/identity/src/lib.rs)屬指定帳號，自訂 UA 或帳號環境適用於推理、[帳號操作](../../crates/upstream/src/ops.rs)及[換票](../../crates/upstream/src/refresh.rs)。照搬 CPR 預設會改變既有帳號對上游呈現的身分。CPR 更新的 macOS 版本及 Apple Terminal 版本屬其平台預設。
- CPR 將工作區匿名化拆成專案別名、用戶目錄、Git 遠端和提交欄位的可編輯步驟，再刪除舊的合併動作。Kin 延續[前次核對的工作區資料契約](2026-11-25-077eab36-main.md)，沒有 CPR 的閘道隱私規則執行器。
- 官方新增的 `EncodedJsonBody::omit_from_logs` 讓呼叫端抑制 trace 本體，Debug 僅顯示長度。它沒有改變送出的位元組或重新導向政策。Kin 使用自己的 reqwest 請求路徑，記錄本體長度與改寫次數，不使用官方的 `EncodedJsonBody` 或其 trace 副本。官方 zstd 1.6.0 更新限於 Bazel 的 MODULE 和鎖檔，Kin 的 Cargo 壓縮依賴沒有對應更新。
- 官方 `core/src/client.rs` 的 Guardian 改動確實會改變特定審查請求的 input。這段轉換需要審查者的 session 來源及啟用設定，只作用在送出前的請求副本。Kin 的 ABI 接收宿主已組裝的 input，不負責改寫審查歷史。官方暫停時保留首筆輸入的修正同樣位於宿主啟動階段。
