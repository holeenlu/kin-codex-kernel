## 串流欄位

官方 `a4ee1058` 與 `98f8a331` 都修改 `codex-rs/core/src/client.rs`。凍結 main 的 HTTP 與 WS 預設帶 `x-codex-exclude-stream-fields: delta.sequence_number,reasoning.added.encrypted_content`，provider 可覆寫或明示空值。這是另一個標頭，先前的 `x-codex-exclude` 控制工具與用量歸屬欄位。

Tap 的 `Accepted::into_stream` 把 HTTP SSE 交回控制面，`Turn::into_stream` 將每個 WS 文字事件包成 SSE。vm2api 的內部白名單也未委派欄位投影。Tap 因此保留上游原始事件。兩個傳輸的整合測試同時檢查上游收到的標頭清單與回傳的完整 SSE，涵蓋文字 delta 上的 `sequence_number` 和初步 reasoning item 的 `encrypted_content`。若日後控制面新增投影契約，可用這兩個案例核對其適用範圍。
