# v0.4.8 單槽核心的本機壓縮與增量續接

## 新增功能

- 單槽核心於 ABI 1 狀態回報封包能力。支援此能力的閘道可透過 Unix socket 傳送 gzip 請求，並在同一對話的後續請求引用已確認的基底。

## 優化

- 減少長對話在閘道與核心之間重送的歷史內容。在 128 KiB 合成資料、每種模式 20 輪的本機測試中，續接請求傳輸量中位數從 132,947 位元組降至 758 位元組。此數據量測本機傳輸，正式站點的首字延遲仍須以部署後的流量評估。

## Bug 修正

- 本版無此項。

## 升級影響

- 既有 ABI 1 JSON 入口可繼續使用。閘道須升級並完成能力協商才能使用新入口。基底淘汰或核心重啟後，核心於送往上游前回報缺失，閘道可補送完整內容。下游請更新兩種架構的載荷釘選。

## 驗證結果

- 通過核心 API 與契約的 83 項測試。本機閘道與核心整合已驗證首次請求、增量續接，以及核心重啟後回退至完整請求且上游只收到一次推理。
