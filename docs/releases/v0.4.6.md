# v0.4.6 — 保留額度限制標頭與模型目錄 ETag

## 新增功能

- Responses 呼叫端現在可從 HTTP 回應取得上游的 `x-models-etag`，用來判斷是否刷新模型目錄。WebSocket 則在新連線首次成功接受生成請求時交付握手取得的 ETag。

## 優化

- WebSocket 預熱會保留握手的 ETag 給第一個生成回合。同一連線後續回合不會重複收到舊值，重新握手後則可取得新值。

## Bug 修正

- HTTP 推理或 WebSocket 握手收到 429 時，舊版會漏傳部分額度標頭。本版會保留上游提供的具名額度桶、視窗、重置時間與點數資訊，讓控制面能依原始回應判讀限制。

## 升級影響

- v0.4.5 可直接升級，沿用 ABI 1／2、現有設定與資料。vm2api 維護者可執行 `python3 scripts/release/sync_tap_payload.py --apply` 驗證本版附件並更新載荷釘選。

## 驗證結果

- 升版前的 Linux 候選程式樹 `49299fcb` 通過 fmt、Clippy、164 項工作區測試與 cargo-deny。HTTP 和 WebSocket 的 429 與 ETag 回歸案例均在 v0.4.5 重現，並在候選版通過。
- 候選版 Linux amd64 與 arm64 建置通過 glibc 2.34 檢查，另通過 87 項斷網 ABI 契約測試。測試範圍與基準記錄於 `docs/sync/2026-11-24-evening-main.md`。
