# v0.4.7 — 統一核心名稱與 Linux 附件

## 新增功能

- 執行檔、`--version`、兩種 ABI 的健康與能力查詢，以及建置記錄均使用 `kin-codex-kernel`。日誌設定可使用 `KIN_LOG` 與 `KIN_LOG_FORMAT`。

## 優化

- HTTP 非串流回應共用一次 SSE 解碼來辨識終態及觀察中途事件計時，減少重複切分和解析事件的成本。

## Bug 修正

- 本版無此項。

## 升級影響

- Linux amd64 與 arm64 分別下載 `kin-codex-kernel-linux-amd64`、`kin-codex-kernel-linux-arm64`，以同名 `.build.json` 及 `SHA256SUMS` 核對。來源倉庫為 `holeenlu/kin-codex-kernel`，兩個平台的安裝位置均為 `bin/kin-codex-kernel`。
- 控制面須依版本核對附件、建置記錄、`health.provider` 與 `describe.kernel`。v0.4.6 及更早版本仍使用原發行名稱。既有 ABI、設定檔、控制面專用標頭及 `TAP_LOG`、`TAP_LOG_FORMAT` 仍可使用，無需遷移資料。

## 驗證結果

- 改名提交在 Rust 1.99.1 通過格式檢查與嚴格 Clippy（macOS，使用內建 OpenSSL），CI 與發版流程通過 actionlint。下游的版本排序、舊建置記錄及新名稱驗證共三項測試通過。
